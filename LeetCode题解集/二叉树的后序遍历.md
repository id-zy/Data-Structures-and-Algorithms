# 二叉树的后序遍历

## 🎯 问题描述（来源于LeetCode）
**描述**：
给你一棵二叉树的根节点 `root` ，返回其节点值的 **后序遍历** 。
**说明**：
- 树中节点的数目在范围 `[0, 100]` 内
- `-100 <= Node.val <= 100`

**示例**：

- 示例 1：

```text
输入：root = [1,2,3,4,5,null,8,null,null,6,7,9]
输出：[4,6,7,5,2,9,8,3,1]
```

- 示例 2：

```text
输入：root = []
输出：[]
```
## 💻 解题思路
### 思路1：递归
#### 思路1：代码实现
```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def postorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
        res=[]
        def PostOrder(Node):
            if not Node:
                return
            PostOrder(Node.left)
            PostOrder(Node.right)
            res.append(Node.val)
        PostOrder(root)
        return res    
```
