# 最长连续递增序列

## 🎯 问题描述（来源于LeetCode）
**描述**：
给定一个未经排序的整数数组，找到最长且 **连续递增的子序列**，并返回该序列的长度。

**连续递增的子序列** 可以由两个下标 `l` 和 `r`（`l < r`）确定，如果对于每个 `l <= i < r`，都有 `nums[i] < nums[i + 1]` ，那么子序列 `[nums[l], nums[l + 1], ..., nums[r - 1], nums[r]]` 就是连续递增子序列。
**说明**：
- `1 <= nums.length <= 104`
- `-109 <= nums[i] <= 109`

**示例**：

- 示例 1：

```text
输入：nums = [1,3,5,4,7]
输出：3
解释：最长连续递增序列是 [1,3,5], 长度为3。
尽管 [1,3,5,7] 也是升序的子序列, 但它不是连续的，因为 5 和 7 在原数组里被 4 隔开。
```

- 示例 2：

```text
输入：nums = [2,2,2,2,2]
输出：1
解释：最长连续递增序列是 [2], 长度为1。
```
## 💻 解题思路
### 思路1：可变长度滑动窗口
#### 思路1：代码实现
```python
class Solution:
    def findLengthOfLCIS(self, nums: List[int]) -> int:
        left,right=0,1
        l,r=0,0
        while right < len(nums):
            be=nums[right-1]
            if nums[right]<=be:
                if r-l+1<right-left:
                    l=left
                    r=right-1
                left=right
            right+=1
        
        if l==r or right-left>r-l+1:
            return right-left
        return r-l+1
```
