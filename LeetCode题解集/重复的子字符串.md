# 重复的子字符串

## 🎯 问题描述（来源于LeetCode）
**描述**：
给定一个非空的字符串 `s` ，检查是否可以通过由它的一个子串重复多次构成。
**说明**：
- `1 <= s.length <= 104`
- `s` 由小写英文字母组成
**示例**：

- 示例 1：

```text
输入: s = "abab"
输出: true
解释: 可由子串 "ab" 重复两次构成
```

- 示例 2：

```text
输入: s = "aba"
输出: false
```
## 💻 解题思路
### 思路1：巧思（看题解）
#### 思路1：代码实现
```python
class Solution:
    def repeatedSubstringPattern(self, s: str) -> bool:
        return (s+s).find(s,1)!=len(s)
```
